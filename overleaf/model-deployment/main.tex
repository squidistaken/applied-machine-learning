\section{Models Results}

Ideal hyperparameters were obtained from a 5-fold cross-validation grid search. Early stopping was implemented with a standard patience of three epochs. We trained with an 80-20 training-validation set split. The test split is already separate from the original data source. Figures \ref{fig:models_metrics} and \ref{fig:models_training_history} demonstrate the results per model.

\begin{itemize}
    \item \textbf{Baseline 3-layer CNN:} On the validation set, loss reported 0.899, macro-f1 score 0.642, precision 0.635, and recall 0.660. On the testing set, loss reported 0.958, macro-f1 score 0.660, precision 0.661, and recall 0.662.
    \begin{itemize}
        \item Learning rate: 0.0001
        \item Batch size: 16
        \item Weight decay: 0.0001
        \item Epochs: 20, stopped at 20.
    \end{itemize}
    \item \textbf{LightGBM:} On the validation set, macro-f1 score reported 0.740, precision 0.756, and recall 0.737. On the testing set, macro-f1 score reported 0.770, precision 0.790, and recall 0.773.
    \begin{itemize}
        \item Learning rate: 0.1
        \item Number of leaves: 15
        \item Maximum depth: -1
        \item Epochs: 150, stopped at 79 from early stopping.
    \end{itemize}
    \item \textbf{Finetuned ResNet-18 CNN:} On the validation set, loss reported 0.609, macro-f1 score 0.738, precision 0.732, and recall 0.757. On the testing set, loss reported 0.507, macro-f1 score 0.831, precision 0.833, and recall 0.829.
    \begin{itemize}
        \item Learning rate: 0.0001
        \item Batch size: 32
        \item Weight decay: 0.0001
        \item Epochs: 10, stopped at 10.
    \end{itemize}
\end{itemize}
